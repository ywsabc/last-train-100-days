# Last Train KubeJS layer

This directory is for reversible compatibility and balance changes:

- recipe edits for Create, TongDa Railway and TaCZ;
- loot-table adjustments;
- tags shared by third-party content;
- short-lived compatibility workarounds.

Do not store campaign day, route, mission or train recovery state here. Those
values live in `lasttrain_campaign.dat` through the server-authoritative core.
